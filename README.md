# Barza Scorecard | بطاقة تقييم الحضور الرقمي

**أداة في المتصفح تقيّم الحضور الرقمي لأي محل من ١٠، وتقترح أهم ٣ تحسينات تلقائياً، وتطبع بطاقة A4 ثنائية اللغة بهوية برزة مع رمز QR لواتساب.**
**A browser tool that scores a local shop's online presence out of 10, suggests the top 3 fixes automatically, and prints a bilingual A4 card with Barza branding and a WhatsApp QR code.**

🔗 **Live:** https://muhanadsaadi.github.io/barza-scorecard/
📦 **Repo:** https://github.com/muhanadsaadi/barza-scorecard

## العربية

### المميزات
- **نموذج بسيط:** الاسم، المنطقة، النشاط، تقييم Google، عدد المراجعات، وخانات: صور، ساعات عمل، قائمة/أسعار، رابط طلب، الرد على المراجعات، معلومات باللغتين، وملاحظات.
- **درجة من ١٠ على ٦ فحوصات** تتحدث فوراً مع كل تعديل.
- **أهم ٣ تحسينات تلقائياً** (قواعد ثابتة، بالعربية والإنجليزية) مرتبة حسب النقاط الضائعة ثم الأسرع تنفيذاً، مع عدد النقاط المتوقع كسبها.
- **بطاقة A4 جاهزة للطباعة** بهوية برزة، حلقة الدرجة، أشرطة الفحوصات، والتحسينات.
- **رمز QR لواتساب برزة** يُولَّد داخل المتصفح (بدون أي خدمة خارجية) مع رسالة جاهزة باسم المحل.
- **طباعة / حفظ PDF** بزر واحد، واسم الملف يتضمن اسم المحل.
- يحفظ آخر إدخال تلقائياً في المتصفح.

### طريقة حساب الدرجة

| # | الفحص | النقاط | القاعدة |
|---|---|---|---|
| 1 | تقييم Google | 2 | ≥4.5 = 2 · ≥4.2 = 1.5 · ≥3.8 = 1 · أقل = 0.5 · لا يوجد = 0 |
| 2 | عدد المراجعات | 2 | ≥200 = 2 · ≥100 = 1.5 · ≥50 = 1 · ≥15 = 0.5 |
| 3 | الصور | 1.5 | موجودة = 1.5 |
| 4 | ساعات العمل والقائمة | 1.5 | 0.75 لكل منهما |
| 5 | رابط طلب مباشر | 1.5 | موجود = 1.5 |
| 6 | التفاعل واللغتان | 1.5 | الرد على المراجعات 1 + معلومات باللغتين 0.5 |

لتغيير القواعد عدّل `RATING_STEPS` و`REVIEW_STEPS` ونصوص التحسينات في `js/scoring.js`. ولتغيير رقم واتساب عدّل `BARZA_WHATSAPP` في `js/app.js`.

### الاستخدام
1. افتح الرابط، واملأ بيانات المحل من ملفه على Google Maps.
2. اضغط **طباعة / حفظ PDF** واختر «حفظ كـ PDF» وحجم A4 (الهوامش: بلا / افتراضي).
3. أرسل البطاقة لصاحب المحل أو اطبعها وسلّمها يداً بيد.

### النشر على GitHub Pages
ارفع الملفات إلى مستودع عام ← **Settings → Pages → Deploy from a branch → `main` / `(root)`**. لا يحتاج خادماً — يعمل أيضاً بفتح `index.html` مباشرة.

## English

### Features
- Simple form: name, area, category, Google rating, review count, six yes/no checks (photos, hours, menu, order link, replies, bilingual info) and notes.
- **Live score /10** across 6 weighted checks (table above).
- **Top 3 fixes** generated by rules, in Arabic + English, sorted by points lost then by quick-win priority, each showing the points it would add.
- **Printable A4 card** with Barza branding, score ring, check bars and fixes.
- **WhatsApp QR** generated fully client-side with a prefilled message mentioning the shop.
- **Print / Save as PDF** — the file name includes the shop name. Last entry is remembered.

### Customise
- Scoring thresholds and fix texts: `js/scoring.js` (`RATING_STEPS`, `REVIEW_STEPS`, `FIX_PRIORITY`).
- WhatsApp number and example shop: `js/app.js` (`BARZA_WHATSAPP`, `EXAMPLE_SHOP`).
- Colours and card layout: CSS variables at the top of `css/style.css`.

### Project structure
```
barza-scorecard/
├── index.html            ← form + A4 card markup
├── css/style.css         ← app layout, A4 sheet, @media print
├── js/scoring.js         ← pure scoring rules (no DOM) – testable with Node
├── js/app.js             ← reads form → scores → renders card, QR, print
├── js/vendor/qrcode.js   ← qrcode-generator (MIT, Kazuhiko Arase), bundled locally
└── assets/barza-mark.svg ← Barza logo mark
```

Quick test from a terminal:
```bash
node -e "const {scoreShop}=require('./js/scoring.js'); console.log(scoreShop({rating:4.3,reviews:64,photos:true,hours:true}))"
```

## How it was built | آلية التنفيذ

- **Tech:** HTML5, CSS3 (mm units for an exact A4 sheet, `@page` + `@media print`), vanilla JavaScript. No frameworks, no backend, no paid APIs.
- **Design:** the scoring rules are a pure function (`scoreShop`) separated from the UI, so they are easy to read, test and adjust. The UI re-renders the whole card on every input; the preview is scaled to fit any screen while the print version is true A4.
- **QR code:** generated locally with the open-source [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) library (MIT) as an SVG, so it stays sharp when printed.
- **AI-assisted development:** planned and built with the help of an AI coding assistant (Claude), then reviewed, tested (desktop, mobile width and print) and customised by me.

- **التقنيات:** HTML وCSS وJavaScript خالص؛ وحدات mm لبطاقة A4 دقيقة وقواعد طباعة خاصة.
- **البنية:** قواعد التقييم دالة مستقلة عن الواجهة يسهل اختبارها وتعديلها، والواجهة تعيد رسم البطاقة مع كل إدخال.
- **تطوير بمساعدة الذكاء الاصطناعي:** تم البناء بمساعدة مساعد برمجة ذكي (Claude)، ثم راجعتُ الكود واختبرته وخصّصته بنفسي.
